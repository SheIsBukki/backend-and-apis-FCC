# Prime Checker

This package is used to to check if a number is a prime number and returns a Boolean.

## Installation

```bash
npm install prime-checker
```

## Usage

```js
const primeChecker = require("./index");
console.log(primeChecker.isPrime(4)); // false
console.log(primeChecker.isPrime(11)); // true
console.log(primeChecker.isPrime(17)); // true
```
